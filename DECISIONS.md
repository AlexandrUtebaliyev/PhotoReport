# Решения

- Месяцы описаны списком `MONTHS` в `config.js` (ключ, подпись, лист, флаг `current`); `November` исключён из расчётов, чтобы не задваивать строки с листом «Фото».
- Колонки ищутся по началу заголовка без регистра; «Вес» проверяется после «Общий вес», «Фото ID» не путается с «Ссылка на фото».
- Записи без даты или без веса показываются («вес не указан»), но в суммы не входят.
- Дата читается как локальное время устройства (в таблице нет часового пояса).
- Марка без количества считается как 1 шт. Тип «Прочее», если название начинается с марки.
- ID записи — `message_id`; если ссылки нет, `r<номер строки>`.
- Добавлены `js/util.js` (форматирование, SVG-иконки) и `js/state.js` (выбранный месяц, фильтр, поиск) — общий код экранов.
- `package.json` содержит только `"type":"module"` и скрипт `test` (зависимостей нет), нужен для `node --test` с ES-модулями.
- Проверка на реальной таблице вынесена в `tools/live-check.mjs` (не попадает в `node --test`).
- `?m=<лист>` меняется через `history.replaceState` без перезагрузки; по умолчанию — текущий лист.
- Двойное нажатие на столбец диаграммы открывает ленту с фильтром по дню (`state.day`).
- «Предыдущая» в карточке — более ранняя запись, «Следующая» — более поздняя; свайп влево = «Следующая», вправо = «Предыдущая».
- Экран карточки скрывает таббар (больше места под фото); каждый экран монтируется в свой контейнер, чтобы обработчики не копились.
- Офлайн-плашка показывается и при `navigator.onLine === false` на свежем кэше, и при неудачном обновлении устаревшего.
- Опечатки типа («Колона», «Клона», латинская K) сводятся к «Колонна» словарём `TYPE_FIX` в `marks.js`.
- Иконки генерирует `tools/make_icons.py` (Pillow); смоук-тест в Chrome — `tools/e2e.mjs` (через CDP, без зависимостей).
- Фото `bot_addon`: `upload_for_message` берёт `message_id` из `photo_link`, т. к. в сценарии FixPhoto в `_write_to_sheets` приходит другое сообщение; бэкфилл ищет файлы через `rglob("msg<id>_*.jpg")`.
- В `ShopLogger` создан только новый `.gitignore` (с `client_secret.json`, `token.json`); файлы бота не менялись.
- Бот найден в `C:\Users\utebaliyev.a\Documents\Projects\ShopLogger` (сверены `get_save_path`, `append_row`, `SAVE_DIR`); файлы фото: `photos/<chat_id>/<YYYY-MM-DD>/msg<message_id>_<unique>.jpg`. `chat_id` в ссылке — без префикса `-100`.
