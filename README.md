# Фотожурнал (PhotoReport)

PWA для просмотра фотожурнала готовой продукции из Google-таблицы бота ShopLogger. Статический сайт: чистые HTML/CSS/JS (ES-модули), без сборщика и зависимостей. Работает на Android и iPhone, ставится на экран «Домой», после первой загрузки открывается и без сети.

Экраны: **Лента** (`#/`), **Карточка записи** (`#/e/<лист>/<id>`), **Сводка** (`#/stats`), **Архив** (`#/archive`). Выбранный месяц — `?m=<лист>`.

## Настройка (`js/config.js`)

**Сменить таблицу.** Замените `SHEET_ID` (часть ссылки между `/d/` и `/edit`). Таблица должна быть открыта «всем, у кого есть ссылка — просмотр». Ключи не нужны.

**Добавить месяц.** В список `MONTHS` добавьте строку (новые — сверху):
```js
{ key: '2026-12', label: 'Декабрь 2026', sheet: 'Фото', current: true },
```
При смене месяца бот продолжает писать в лист «Фото». Перед этим скопируйте прошлый месяц в лист с его названием (например `November`), добавьте его в `MONTHS` как архивный (без `current`), а у декабря поставьте `current: true` и снимите `current` с ноября. Месячный лист, дублирующий текущий месяц, в `MONTHS` не добавляйте — строки задвоятся. `Copy of Фото` приложение не читает.

**Дополнить словарь заказчиков.** В `CLIENT_ALIASES` добавьте пару `'вариант написания': 'Единое название'`. Регистр и лишние пробелы не важны. Неизвестные варианты остаются как есть.

**Режим фото.** `PHOTO_MODE = 'drive'` — миниатюры из Google Drive по колонке «Фото ID»; `'none'` — только заглушки.

## Фото из Google Drive

Ссылки `t.me/c/...` ведут в закрытую группу, картинку по ним показать нельзя. Бот должен загружать фото в Google Drive и писать ID файла в колонку «Фото ID» (F). Готовые модули лежат в `bot_addon\`:

- `drive_upload.py` — загрузка от имени пользователя (OAuth; сервисный аккаунт не подходит — `storageQuotaExceeded`). Нужны `client_secret.json` (Desktop app) и `token.json` (создаётся при первом запуске).
- `backfill_photos.py` — дозаполнение старых записей (`--dry-run` по умолчанию, `--apply`).
- `BOT_PATCH.md` — пошаговая инструкция, какие 3–5 строк вставить в `bot.py` и `sheets.py`, и как перенести модули в папку бота (`D:\Documents\Projects\metal_bot`).
- `requirements_addon.txt` — зависимости (`pip install -r requirements_addon.txt`).

`client_secret.json` и `token.json` внесены в `.gitignore` и не должны попасть на GitHub.

## Как устроено

| Файл | Назначение |
|---|---|
| `js/config.js` | ID таблицы, месяцы, словарь заказчиков, режим фото |
| `js/data.js` | CSV-парсер, нормализация, кэш в `localStorage` (лист «Фото» — 1 мин, архив — 24 ч), загрузка |
| `js/marks.js` | `parseMarks`, тип конструкции |
| `js/views/*.js` | экраны: лента, карточка, сводка, архив |
| `sw.js` | app shell — cache-first; CSV — network-first с откатом на кэш; версия кэша `VERSION` |

После правки файлов приложения увеличьте `VERSION` в `sw.js`, иначе у пользователей останется старая оболочка.
